# Homework: Superloop and Independent Tasks

## Submission

- Code and execution results on GitHub.
- Repository link submitted in the LMS.

## Task

Manage several independent processes within a single `loop()` without blocking.

There are 3 LEDs:

- **LED1** blinks every **200 ms**
- **LED2** blinks every **500 ms**
- **LED3** blinks every **1000 ms**

## Requirements

- ❌ Using `delay()` is **forbidden**
- ❌ Using `while()` to wait for time inside `loop()` is **forbidden**
- ✅ Using `millis()` is **allowed**
